## 경험 구분

- 네트워크·PC 유지보수는 **실무 경험**입니다.
- Python·Docker·PostgreSQL·Kotlin/Spring Boot는 **AI 협업 개인 프로젝트**의 활용 기술입니다. 상용 서버 운영 경력이나 단독 개발 성과와 구분합니다.
- Linux는 자격 기반 기초이며, 별도의 상용 Linux 운영 경력으로 주장하지 않습니다.
- 프로젝트별 실행 시점·환경·검증 제외 범위는 [검증 기록](https://github.com/jisub-lee-0906/engineering-portfolio/blob/main/docs/verification.md)에 공개합니다.

AI 도구 활용 사실과 기여 범위를 숨기지 않습니다. 2026-10-07 문서 개편·신규 실행 점검은 AI 에이전트가 수행했으며, 지원자 본인의 직접 재현·검토와 구분합니다.
